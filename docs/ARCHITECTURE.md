# KHNP 인재개발원 AI 기반 교육컨텐츠 생성 시스템
## Slides-to-Script & Question Bank Generator PoC

---

## 1. 프로젝트 비전

한국수력원자력 인재개발원의 SAT(Systematic Approach to Training) 기반 직무교육 체계를 AI로 고도화하여,
**강의안(슬라이드) → 고품질 강의 스크립트 + 문제은행**을 자동 생성하는 세계 최고 수준의 교육컨텐츠 환류 시스템 구축

### 핵심 가치
- **SAT 5단계 연계**: Analysis → Design → Development → Implementation → Evaluation
- **온프레미스 보안**: 원자력 산업 규제 환경에 적합한 데이터 주권 확보
- **교육 품질 표준화**: 강사 역량 편차 해소, 일관된 교육 품질 보장
- **지식 환류**: 교육 → 평가 → 피드백 → 교육 개선의 선순환 구조

## 3. 핵심 파이프라인 상세

### 3.1 문서 처리 파이프라인 (Document Processing)

| 단계 | 기술 | 설명 |
|------|------|------|
| 슬라이드 입력 | PDF/PPTX | 강의안 원본 파일 수집 |
| 레이아웃 분석 | Upstage Document Parse | 문단, 표, 이미지, 수식, 차트 자동 감지 |
| VLM 분석 | Upstage Document Parse Enhanced | 복잡한 시각 요소(다이어그램, 차트) 의미 해석 |
| 구조화 | HTML/JSON 변환 | 읽기 순서 보존, 표 구조 인식 |
| 메타데이터 | SAT 태깅 | 학습목표, 역량단위, 난이도 자동 태깅 |

**Upstage 활용 포인트:**
- `Document Parse Standard`: 일반 슬라이드 텍스트/레이아웃 추출
- `Document Parse Enhanced`: 원자력 설비 도면, 계통도, P&ID 등 복잡 시각자료 해석
- `OCR`: 95%+ 정확도의 텍스트 인식
- `Solar VLM`: 시각 자료에 대한 자연어 설명 생성

### 3.3 생성 엔진 (Generation Engine)

#### A. 강의 스크립트 생성
```
입력: 파싱된 슬라이드 + RAG 컨텍스트 + SAT 학습목표
  ↓
프롬프트 엔지니어링:
  - 슬라이드별 강의 멘트 생성
  - 도입-전개-정리 구조
  - 핵심 용어 설명 포함
  - 실무 사례/경험 반영 (RAG)
  - 학습자 수준 맞춤 (초급/중급/고급)
  ↓
출력: 슬라이드별 강의 스크립트 (시간 배분 포함)
```

#### B. 문제은행 생성
```
입력: 파싱된 교재 내용 + RAG 컨텍스트 + SAT 평가기준
  ↓
문제 유형별 생성:
  - 지식(Knowledge): 사실 확인형
  - 이해(Comprehension): 개념 설명형
  - 적용(Application): 실무 상황형
  - 분석(Analysis): 원인 분석형
  ↓
품질 검증:
  - 정답 확인 (RAG 기반 fact-check)
  - 오답 매력도 검증
  - 난이도 분포 확인
  - SAT 학습목표 커버리지 검증
  ↓
출력: 문제은행 (문제, 보기, 정답, 해설, 메타데이터)
```

## 4. SAT 연계 설계

### IAEA SAT 5단계와 시스템 매핑

| SAT 단계 | 시스템 기능 | AI 활용 |
|----------|------------|---------|
| **Analysis** | 직무분석(JTA) 결과 입력, 학습목표 매핑 | RAG로 관련 규정/절차서 자동 연계 |
| **Design** | 교육과정 설계 템플릿, 평가 기준 설정 | 학습목표 기반 콘텐츠 구조 자동 제안 |
| **Development** | 강의 스크립트/문제은행 생성 | Document AI + LLM 기반 자동 생성 |
| **Implementation** | 교육 실행 지원, 강사 가이드 | 맞춤형 스크립트, 시간 배분 제안 |
| **Evaluation** | 평가 결과 분석, 피드백 반영 | 문항 분석, 변별도/난이도 통계 |

## 8. Upstage/EY 협력 사항

### Upstage 확인 필요 사항
1. Document Parse On-Premise 배포 옵션 (Docker/Kubernetes)
2. Solar Pro 온프레미스 라이선싱 모델 및 가격
3. 원자력 도메인 특화 Fine-tuning 가능 여부
4. 내부망(Air-gapped) 환경 지원 범위
5. Embedding 모델 온프레미스 제공 여부
6. SLA 및 기술지원 범위

### EY 확인 필요 사항
1. AI 전략 수립 관점에서의 PoC 범위 적정성
2. 원자력 산업 AI 규제/컴플라이언스 가이드라인
3. ROI 분석 프레임워크
4. 확산 전략 (인재개발원 → 본사/발전소)
5. 변화관리 전략 (강사/교육담당자 수용성)
6. 벤치마킹 사례 (글로벌 원자력 교육 AI 적용)
