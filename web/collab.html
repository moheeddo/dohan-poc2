프로젝트 개요

⚡ 프로젝트 목표

강의안(슬라이드)을 Upstage Document AI로 정밀 파싱하고, 도메인 지식(규정/절차서/사고사례)을 RAG로 증강하여, 고품질 강의 스크립트와 SAT 기반 문제은행을 자동 생성합니다.

핵심 차별점:
  • 원자력 도메인 특화 (설비도면, P&ID, 계통도 해석)
  • IAEA SAT 표준 완벽 연계
  • 온프레미스 배포 (데이터 주권, 원자력 보안규정 준수)
  • 교육-평가-환류 전주기 자동화

💬 프로젝트 개요 관련 의견

PoC 단계 RAG 전략
풀스케일 RAG 구축 없이 "RAG 효과"를 입증하는 실용적 접근법

PoC 핵심 판단

PoC 단계에서 대규모 RAG 인프라(벡터DB + 수만건 임베딩)를 구축하는 것은 과도합니다.
대신 "Golden Context 방식"으로 RAG와 동등한 효과를 데모하고,
A/B 비교를 통해 "본격 RAG 구축 시 더 좋아진다"는 투자 정당성을 확보합니다.

★ 채택: Golden Context + Curated Prompt

강의안 업로드 시 관련 참고자료(절차서/규정)를 함께 첨부. 별도 벡터DB 없이 파싱 후 LLM 컨텍스트에 직접 주입.

  • Golden Context: 참고자료 2~5건 함께 업로드
  • Curated Prompt: SAT/Bloom/용어사전 내장
  • Few-shot: SME 모범 예시 5건 확보

📊 A/B 비교 데모 전략 — PoC의 킬러 장면

A: 강의안만
Input: 강의안 PDF 1건
Context: 없음
→ 일반적 설명, 전문용어 부정확 가능
VS
B: 강의안 + 참고자료
Input: 강의안 + 절차서 2건 + 규정 1건
→ 전문용어 정확, 규정 인용, 실무 맥락 반영
피칭: "참고자료 3건만 넣어도 이 차이. 본격 RAG로 수천 건 연결하면 훨씬 더 좋아집니다."

⚠ AI 문항 품질 검증 (QA) — 가장 중요

연구 결과: AI 생성 문항의 비기능적 오답 비율 33.75% vs 인간 출제 13.75%. → 오답 매력도 검증이 최우선 과제
검증 단계검증 내용통과 기준
1. 지문 명확성모호한 표현, 이중해석모호성 0건
2. 정답 정확성정답 오류, 복수 정답참고자료에서 확인
3. 오답 매력도각 오답 선택 합리적 이유?비기능적 오답 0건
4. 난이도 적정성Bloom 수준 대비 매칭난이도 0.3~0.7
5. SAT 정합성학습목표 직접 연계미연계 0건
6. Bloom 분포수준별 배분 준수각 수준 ±10%

⚡ 2-Pass 문항 생성 엔진

AI 오답 33.75%가 비기능적인 문제를 생성 시점에서 해결

Pass 1: 오답별 distractor_rationale 필수 기술

Pass 2: 약한 오답 감지 → 대체 오답 + 새 근거 생성

목표: 비기능적 오답 33.75% → 10% 이하
