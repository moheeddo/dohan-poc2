원자력 산업 특수 요구사항 매칭
Nuclear Industry Requirements
  1. 1
    기술 주권 (Technology Sovereignty)
    원자력 핵심 기술은 국산/독자 기술 사용이 원칙. 중국 기술 의존 모델은 규제/감사 시 리스크. Solar는 정부(과기정통부) 독자성 검증을 통과한 유일한 소규모 파라미터 모델.
    CRITICAL
  2. 2
    내부망 독립 운영 (Air-Gapped Operation)
    원자력 시설 내부망은 외부 인터넷 차단 환경. NCloud 종속 = 운영 불가. Solar Docker = 완전 독립 운영 가능.
    CRITICAL
  3. 3
    문서 파싱 전문성 (Document Intelligence)
    원자력 교육자료는 설비도면, P&ID, 계통도 등 복잡한 시각자료 다수. HyperCLOVA X는 이를 파싱할 전문 기능이 없음. Upstage Document Parse Enhanced는 이를 위해 설계된 전문 제품.
    CRITICAL
  4. 4
    벤더 독립성 (Vendor Independence)
    네이버 Neurocloud = H/W+S/W 패키지 종속. KHNP 기존 IT 인프라(GPU 서버)에 Docker만 올리면 되는 Solar가 TCO 유리.
    IMPORTANT

Decision Rationale for Stakeholders

1. "본사가 쓰는 HyperCLOVA X 안 되나요?"에 대한 답변:

HyperCLOVA X는 범용 챗봇/검색에 최적화된 모델입니다. 우리 프로젝트는 강의안 파싱 + 구조화 + 생성이 핵심이며, 이를 위해서는 Document AI 전문 기능이 필수입니다. 네이버에는 이 기능이 없고, Upstage에만 있습니다.

2. "네이버가 더 큰 회사 아닌가?"에 대한 답변:

네이버 HyperCLOVA X는 정부 독파모 심사에서 중국 기술 의존으로 탈락했습니다(2026.01). 원자력 산업은 기술 주권이 핵심 가치이며, KINS/원안위 보안 심사 시 중국 기술 의존 모델 사용은 리스크입니다. Upstage Solar는 독파모 통과 = 정부 검증 완료된 독자 기술입니다.

3. "비용은?"에 대한 답변:

Solar Pro = A100 80GB 1장으로 구동 (기존 GPU 서버 활용 가능).
네이버 Neurocloud = 전용 H/W+S/W 패키지 도입 필요 (수억원 규모 추정).
Solar는 Docker 이미지 라이선스 비용만 발생 → TCO 압도적 우위.

왜 VLM이 핵심인가?

원자력 강의안의 30~50%는 시각자료(설비도면, P&ID, 계통도, 운전 파라미터 차트)입니다. 텍스트만 파싱하면 강의 내용의 절반을 놓칩니다.

Document Parse Enhanced + Solar VLM 2단계 분석:
  1. 1단계 (Document Parse Enhanced): 이미지/차트를 감지하고, VLM으로 구조화된 설명(자연어 + 데이터) 생성
  2. 2단계 (Solar Pro 심층 분석): 1단계 결과를 원자력 도메인 맥락에서 재해석하여 교육용 설명 생성
Upstage 확인 필요: Document Parse Enhanced가 원자력 P&ID/계통도를 얼마나 정확하게 구조화하는지 샘플 테스트 필요. 정확도가 부족하면 2단계 Solar Pro 분석의 품질도 저하됨.

핵심 아이디어: AI 오답의 33.75%가 비기능적인 문제를 생성 시점에서 해결. 1차 생성에서 "오답 선택 이유"를 강제로 기술하게 하고, 2차 검증에서 약한 오답을 자동 교체.
Pass 1: 생성 + 오답 근거
  • 각 오답에 distractor_rationale 필드 필수
  • "학습 부족자가 이 오답을 선택할 수 있는 구체적 이유"를 기술
  • 모든 보기에 합리적 선택 이유가 있어야 통과

Pass 2: 오답 정제(Refine)

  • "학습자 30%가 선택할 수 있는가?" 테스트
  • 약한 오답 감지 시 대체 오답 + 새로운 근거 생성
  • 최종 distractor_quality_score 부여 (1~5점)
기대 효과: 비기능적 오답 비율 33.75% → 목표 10% 이하 (인간 출제 수준 13.75% 달성 목표)
